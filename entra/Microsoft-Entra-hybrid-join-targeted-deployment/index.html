    Microsoft Entra hybrid join targeted deployment

    Overview

    ปัจจุบัน เครื่องคอมพิวเตอร์ส่วนใหญ่ยัง join on-premises AD DS อยู่ เราสามารถนำเขาไป join Entra ID โดยอัตโนมัติได้ด้วยการ enable Entra Hybrid Join

    แต่เรามี 2 ทางเลือก

    • ทางเลือกแรก - รีรัน Entra Connect tool เพื่อสร้าง Service Connection Point (SCP) ให้ทุกเครื่องที่ join on-premises AD DS มองเห็น แล้ว device จะใช้ข้อมูล Tenant ID และ Tenant name เข้าไปทำ Entra Hybrid Join เข้า Entra ID

    • ทางเลือกที่ 2 - ทำให้ device รู้จักกับ SCP แค่บางเครื่อง จาก Microsoft Entra hybrid join targeted deployment ผ่าน GPO settings

    เมื่อ on-premises device มี identity ใน Entra ID จะได้รับประโยชน์จาก SSO, การเป็นสมาชิกของ device group, ใช้ทำ device-based authentication ใน Condtional Access, และอื่นๆ ต่อไป

    และเนื่องจากใน CSoG เราเน้นให้ทุกคนสามารถทำด้วยตัวเองได้ และไม่กระทบกับระบบที่ใช้งานอยู่เป็นวงกว้าง ดังนั้น ขั้นตอนด้านล่างนี้จึงเป็นของทางเลือกที่ 2 Targeted deployment นะครับ

    1. Create a pilot device group

    สร้าง device group สำหรับ pilot Entra Hybrid Join

    2. Configure GPO settigs to enable Entra Hybrid join targeted deployment

    1. Copy ค่า Tenant ID และ Tenant name เพื่อนำไปใช้ตั้งค่า settings ใน GPO

    2. สร้าง GPO และตั้งค่า settings ตาม Configure client-side registry setting for SCP

    3. ที่ Security Filtering

    • ลบ Authenticated Users ออก
    • แล้วเพิ่ม pilot device group เข้าไป

    ที่ tab Delegation, ให้สิทธิ์ Read กับ Authenticated Users

    3. Configure synchronization scopes to sync clients to Entra ID

    รีรัน Entra Connect แล้วเลือก OU ที่มี device ที่ต้องการ sync ไปยัง Entra ID

    หลังจากตั้งค่าทุกอย่างเรียบร้อย เราก็ไปทดสอบ pilot device เครื่องแรกกันนะครับ

    4. Test a client

    4.1 Prepare and restart the pilot client

    1. ย้าย client มาอยู่ใน OU ที่ถูก sync ขึ้น Entra ID

    2. เพิ่ม client เข้าไปเป็นสมาชิกของ pilot device group (ที่ GPO Entra Hybrid Join apply เข้าหา)

    3. แล้ว restart เครื่อง client (device)

    4.2 Wait #1

    1. Client ทุกเครื่องจะมี scheduled task ชื่อว่า Automatic-Device-Join อยู่

    Task จะทำงานทุกๆ 1 ชั่วโมง หรือเมื่อมี user sign in เข้าเครื่อง

    ดังนั้น เพียงแค่เรารอ (ไม่ต้อง sign in เข้า Windows ก็ได้) ก็จะมีเครื่องปรากฏใน Entra ID แต่ยัง้มี state เป็น Pending อยู่

    ซึ่งเราอยากให้กระบวนการ Entra Hybrid Join เริ่มเลย เราก็ sign in เข้าเครื่อง

    2. เมื่อ Automatic-Device-Join task ถูก trigger ให้ทำงานตอนที่ user sign in

    เข้าจะ generate self-signed certificate บนเครื่อง แล้วส่ง public key part ไปแปะไว้ใน computer account ของตัวเองใน AD DS

    Entra Connect จะยอม sync computer object ที่ userCerticiate มีค่า (ไม่เท่ากับ null) ขึ้นไปยัง Entra ID

    แต่ Entra Connect จะทำงานทุกๆ 30 นาที

    ถ้าเราไม่อยากรอ ก็สามารถ force sync ได้เลยนะครับ

    ตอนนี้ client ถูก sync ขึ้นมาที่ Entra ID แล้ว

    แต่สถานะยังเป็น "Pending" ซึ่งเราจะต้องรอให้ Automatic-Device-Join task เข้ามาทำ authentication อีกครั้ง

    4.3 Trigger #2

    ถ้าเราไม่อยาก sign in ใหม่ หรือไม่อยากรอให้ task รันทุกๆ 1 ชั่วโมง

    ก็ลอง force Automatic-Device-Join task รันเองเลยก็ได้

    และ client จะเข้าไปทำ authentication กับ Entra ID อีกครั้ง แล้วเครื่องก็จะกลายเป็น Entra Hybrid joined device จนสมบูรณ์ครับ
